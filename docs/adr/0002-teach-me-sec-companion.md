# AppSec pair companion, not a fourth review

The published GitHub repo is `daviduartedev/skills`. V0.2 added `smoke-test-list` beside the AppSec pair. The collection now also publishes `teach-me-sec`: a working-literacy companion of `security-design-review` and `security-review`. It writes a derived `docs/security/<feature-slug>-explained.md` and a conversation copy; it adds no `THREAT-*`, `SEC-*`, or `SR-*`. Dispatch of the pair when no source exists is an in-skill branch after confirmation, not a second `Use when`. Scanners and SDD orchestrators stay out; further skills still need a spec.
